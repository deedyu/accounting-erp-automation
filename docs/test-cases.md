# QA 테스트 케이스

## 추가 25건 요약

대상: [test_validation_extended.py](../tests/test_validation_extended.py). 아래 ID는 문서에서 입력별 검사를 식별하기 위한 번호다. 매개변수별 실행을 각각 1건으로 계산한다.

공통 기준은 2026년 8월 회계기간, 활성 계정·거래처·부서, 차변·대변 110원, 공급가액 100원·세액 10원의 정상 전표다. 각 검사는 필요한 값만 바꾼다.

| ID | 분류·건수 | 입력·조건 | 기대 결과 | 검증 위험 |
| --- | --- | --- | --- | --- |
| A01 | 정상 1건 | 정상 전표 검증·상태 분류 | 오류 0건, 입력 가능, 원본 동일 | 정상 거래 오탐·원본 변경 |
| A02–A05 | 오류 4건 | 적요가 `None`, `NaN`, 빈 문자열, 공백 | 적요의 필수값 누락·ERROR, 행 번호 2·행 ID r2 | 결측 표현에 따른 탐지 누락·오류 위치 오연결 |
| A06–A09 | 경계값 4건 | 7/31, 8/1, 8/31 23:59:59, 9/1 | 각각 기간 이탈, 정상, 정상, 기간 이탈 | 회계기간 시작·종료 포함 여부 오류 |
| A10–A16 | 경계값 7건 | -1, 0, 1, 최대값 M, M+1, 무한대, `True` | -1·0은 금액 불허, 1·M은 정상, 나머지는 금액 형식 오류 | 음수·0원 허용, 범위 초과·잘못된 자료형 통과 |
| A17–A21 | 경계값 5건 | 허용오차 1원 설정, 예상 세액과 차이 -2/-1/0/+1/+2원 | ±2원은 부가세 계산 오류, -1/0/+1원은 정상 | 허용오차 끝점·양방향 비교 오류 |
| A22–A24 | 경계값 3건 | 공급가액 5원·세율 10%, HALF_UP/HALF_EVEN/DOWN | 세액을 각각 1/0/0원으로 입력하면 정상 | 설정별 0.5원 처리 불일치 |
| A25 | 경계값 1건 | 표준 열이 있는 전표 0건 | 빈 오류 결과·분류 결과, 결과 열 유지 | 빈 입력에서 예외·출력 구조 손실 |
| **합계** | **정상 1 + 오류 4 + 경계값 20 = 25건** | | | |

M은 프로그램의 금액 상한 **9,007,199,254,740,991원**이다. 금액 검사는 면세·차대변 균형을 유지해 금액 자체의 문제를 확인한다. 세액 오차 검사도 총액과 차대변을 맞춰 세액 비교를 분리한다.

기본 세액 허용오차는 0원이며, A17–A21만 1원 설정을 사용한다. 반올림 3종은 기존 validator가 지원하는 정책이고 기본값은 `ROUND_HALF_UP`이다. 새 업무 정책을 추가한 테스트가 아니다.

## 기존 테스트의 대표 사례

| 분류 | 입력·상황 → 기대 결과 | 테스트 함수·파일 |
| --- | --- | --- |
| 오류 | 잘못된 코드·금액·날짜 → 해당 오류 탐지, 원본 행 번호 유지, 입력 불가 | `test_errors_block_erp` · `test_validation_extended.py` |
| 오류 | 중복 전표·증빙, 전표번호 누락 → 오류 탐지 및 행별 상태 분리 | `test_duplicates_and_missing_ids` · `test_validation_extended.py` |
| 정상·오류 | 500건 합성 샘플 → 기존 정답 오류 50개 모두 탐지, 현재 정책 총 오류 66개 | `test_existing_error_reference` · `test_regression.py` |
| 정상 | 입력 가능 전표 변환 → 검토 전표 제외, 전표·금액 보존, 차대변 일치 | `test_erp_preserves_vouchers_and_amounts` · `test_regression.py` |
| 오류 | DB 저장 중 외래키 오류 주입 → 해당 실행 롤백, 이전 실행 보존 | `test_missing_voucher_history_and_rollback` · `test_database_atomic.py` |

위 대표 사례는 전체 목록이 아니다. 전체 실행 판정은 [테스트 결과](test-result.md)에 기록한다.
