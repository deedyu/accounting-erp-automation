# 사용자 안내

1. 프로젝트 루트에서 `python -m streamlit run app.py`를 실행합니다.
2. .xlsx/.xlsm 분개장을 업로드합니다. 원래 파일명은 화면과 이력에 보존됩니다.
3. 처리할 시트를 선택합니다. 헤더·첫 데이터 행·마지막 데이터 행은 Excel의 1부터 시작하는 번호입니다.
4. 가로형 또는 세로형을 확인합니다. 범위 밖 자료는 원본 파일에 남습니다.
5. 자동 매핑 결과를 확인하고 `적용할 표준 열`을 선택합니다. 같은 표준 열은 중복 선택할 수 없습니다. 미매핑 값은 결과의 source_details.xlsx에 보존됩니다.
6. 필요하면 회사별 매핑 JSON을 내려받거나 기존 설정을 불러옵니다. 과거 파일에만 있던 열은 설정에서 정리해 주세요.
7. 회계기간 시작일과 종료일을 확인합니다. 종료일은 포함하지 않습니다.
8. 분석을 실행합니다. 입력 가능/검토 필요/입력 불가 KPI를 확인합니다.
9. 오류의 원본 행 번호와 상세 원인을 확인합니다. 오류 데이터를 임의로 승인하거나 0원으로 보정하지 않습니다.
10. 조회 월·날짜·전체 또는 정상 범위를 선택해 일계표를 확인합니다. 금액은 원 단위와 천 단위 쉼표로 표시합니다.
11. ERP CSV·Excel·JSON과 검토·오류·일계표·요약 파일을 다운로드합니다. ERP 대상은 입력 가능한 전표만 포함합니다.
12. 상단 `이전 실행 이력`에서 저장한 실행 결과를 다시 조회합니다. 구버전 DB는 별도 펼침 영역에서 요약을 확인합니다.

## 주의할 입력
빈 파일이나 정상 전표가 없는 파일도 결과 파일을 만들 수 있습니다. 필수 열이 없는 자료는 원본 값을 임의로 채우지 않고 검증 오류로 보냅니다.
계정코드·부서코드 등의 선행 0이 필요하면 Excel 텍스트 형식으로 보관하세요. 수식은 Excel에서 계산한 후 저장해야 합니다.
날짜 오류 전표는 일별 합계에서 빠지지만 전체 기간 합계에는 해석 가능한 금액이 반영됩니다. 해석할 수 없는 금액이 있으면 합계가 완전하지 않으므로 오류 목록을 먼저 검토하세요.
매핑·기간·범위를 바꾸면 이전 화면 결과가 초기화됩니다. 다시 실행해 변경 사항을 적용하세요.
결과 폴더를 직접 지정할 때는 비어 있는 새 폴더를 사용하세요. 기존 폴더의 결과를 덮어쓰지 않습니다.

## ERP 연계
현재는 ERP 업로드용 파일 생성 및 연동 준비 단계입니다. 실제 ERP 자동 전기는 ERP API, 업로드 양식, DB 인터페이스 또는 RPA 환경이 확보된 후 추가할 수 있습니다.
