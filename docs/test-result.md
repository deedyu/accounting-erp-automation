# QA 테스트 결과

**전체 90건 통과. 실패·건너뜀 없이 기존 65건과 추가 25건을 함께 확인했다.**

## 실행 증거

| 항목 | 결과 |
| --- | --- |
| 확인일 | 2026-10-05 |
| 환경 | 로컬 macOS, Python 3.12.14 가상환경, pytest 7.4.4 |
| 대상 | 현재 작업 디렉터리의 전체 `tests/` |
| 실행 명령 | `.venv/bin/python -m pytest -q` |
| 최종 출력 | `90 passed, 3 warnings in 13.54s` |
| 실패 / 건너뜀 / 예상 실패 | 0 / 0 / 0 |

설치 절차는 [README](../README.md#테스트)에 있으며, 위 명령은 이번 실행의 재현 정보다. 실행 시간은 환경에 따라 달라진다.

## 결과 해석

| 확인 항목 | 관찰 결과 | QA 의미 |
| --- | --- | --- |
| 추가 25건 | 정상 1건·오류 4건·경계값 20건 모두 통과 | 정상 전표 보존, 결측 탐지, 기간·금액·세액 경계의 기대 동작 확인 |
| 기존 65건 | 회귀·통합·화면·실행 호환성 검사 통과 | 이번 테스트 보강 후 기존 검증 범위 내 동작 유지 |
| 샘플 정답 대조 | 주입 오류 50개 모두 탐지, 현재 정책 오류 66개 | 기존 정답의 미탐지 없음; 추가 정책 탐지와 구분 |
| ERP 변환 | 입력 가능 449건, 검토 대상 51건, ERP 1,347행 기준 충족 | 검토 대상 제외와 전표별 금액 보존 확인 |
| 실패 복구 | DB 롤백·기존 데이터 보존 검사 통과 | 중간 실패로 불완전한 실행 이력이 남는 위험 검증 |

추가 25건의 입력·기대값·검증 위험은 [테스트 케이스](test-cases.md)에 정리했다. 90건은 pytest 실행 항목 수이며 거래 건수나 테스트 함수 개수가 아니다.

## 경고와 판정 범위

| 경고 | 건수 | 발생 위치·의미 |
| --- | --- | --- |
| `AltairDeprecationWarning` | 1 | Streamlit 내부의 이전 테마 API 사용; 향후 의존성 호환성 확인 대상 |
| `FutureWarning` | 2 | 기존 집계 회귀 테스트의 pandas `fillna` 자료형 자동 변환; 향후 동작 변경 예고 |

경고는 숨기지 않았으며 이번 실행에서는 실패를 유발하지 않았다. 문서 작성 과정에서 애플리케이션·테스트 코드는 수정하지 않았다.

판정은 **현재 설정·합성 데이터·자동화된 검증 범위에서 통과**다. 실제 ERP 연동 성공, 세무 적합성, 전체 코드 커버리지를 입증하는 결과는 아니다. 검증 범위와 제외 항목은 [테스트 계획](test-plan.md)을 따른다.
