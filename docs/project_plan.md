# 제조기업 회계 분개장 ERP 입력 지원 및 오류 검증 자동화

## 1. 프로젝트 배경

제조기업 경영사무 인턴으로 근무하면서 엑셀 분개장의 거래 정보를
회계 ERP에 건별로 직접 입력했다.

입력 과정에서는 거래일자, 차변·대변 계정과목, 금액, 거래처,
적요, 부가세 및 증빙정보를 반복적으로 확인해야 했다.

수작업 입력은 시간이 오래 걸릴 뿐만 아니라 금액 오입력,
계정과목 선택 오류, 필수값 누락, 중복 입력 등이 발생할 가능성이 있다.

## 2. 프로젝트 목표

엑셀 분개장을 ERP 입력 규격에 맞게 자동으로 변환하고,
입력 전에 오류와 검토 필요 항목을 탐지하는 시스템을 구현한다.

자동화 결과를 바로 확정하지 않고 담당자가 검토한 후
ERP 업로드용 파일을 생성하는 방식으로 설계한다.

## 3. 주요 사용자

- 회계 ERP에 전표를 입력하는 실무 담당자
- 전표의 오류와 처리 현황을 확인하는 회계 관리자
- 회계업무 처리 현황을 확인하는 경영 관리자

## 4. 기존 업무 흐름

1. 담당자가 엑셀 분개장을 확인한다.
2. 거래일자와 거래처를 ERP에 입력한다.
3. 차변·대변 계정과목과 금액을 입력한다.
4. 적요, 부가세 및 증빙정보를 입력한다.
5. 입력 결과를 원본 분개장과 대조한다.
6. 오류가 발견되면 ERP 전표를 수정한다.

## 5. 개선 업무 흐름

1. 프로그램이 엑셀 분개장을 불러온다.
2. 날짜, 금액, 거래처 및 계정과목 형식을 표준화한다.
3. 분개장 데이터를 ERP 입력 형식으로 변환한다.
4. 중복, 누락 및 회계 규칙 위반 항목을 탐지한다.
5. 정상·검토 필요·오류 상태로 분류한다.
6. 담당자가 검토한 데이터를 ERP 업로드용 파일로 저장한다.
7. 처리 결과와 오류 현황을 대시보드로 제공한다.

## 6. 주요 기능

### 데이터 불러오기 및 표준화

- 엑셀 분개장 불러오기
- 거래일자 형식 통일
- 금액 데이터 형식 변환
- 계정과목 및 거래처 코드 연결
- 적요 텍스트 정리

### 오류 검증

- 필수 입력값 누락 확인
- 차변·대변 합계 일치 확인
- 존재하지 않는 계정과목 확인
- 존재하지 않는 거래처 확인
- 동일 증빙번호 중복 확인
- 부가세 계산 오류 확인
- 마감 기간 이후 거래 확인
- 비정상 금액 확인

### 입력 지원

- 적요와 거래처를 기반으로 계정과목 후보 추천
- ERP 업로드 규격의 CSV 파일 생성
- 검토가 필요한 전표 별도 추출
- 검증 결과 보고서 생성

### 대시보드

- 전체 처리 건수
- 정상·검토 필요·오류 건수
- 오류 유형별 발생 현황
- 부서 및 거래처별 오류 현황
- 계정과목 추천 결과
- 월별 처리시간 및 오류 추이

## 8. 데이터 범위

본 프로젝트에서는 실제 기업의 회계자료를 사용하지 않는다.

가상의 자동차부품 제조기업에서 발생한 거래를 기반으로
합성 분개장 데이터를 생성한다.

회사명, 거래처, 금액, 계정과목 코드 및 증빙정보는
모두 프로젝트를 위해 가상으로 설계한다.

## 9. 구현 범위

### 포함

- 가상 분개장 데이터 생성
- 데이터 전처리 및 ERP 규격 변환
- 오류 검증
- 계정과목 추천
- 검증 결과 저장
- ERP 업로드용 파일 생성
- 처리 현황 대시보드

### 제외

- 실제 기업 ERP 접속
- ERP 데이터베이스 직접 수정
- 회계전표의 무인 자동 승인
- 실제 기업 및 거래처 데이터 사용
- 세무신고 자동화

## 10. 기대 효과

- 반복적인 ERP 입력 작업 감소
- 입력 전 오류 사전 발견
- 전체 전표가 아닌 예외 항목 중심의 검토
- 분개장과 ERP 입력 데이터의 일관성 향상
- 회계 처리 현황의 시각적 관리

## 11. 프로젝트 한계

가상의 업무 규칙과 합성 데이터를 사용하므로
특정 기업의 실제 ERP 규격 및 회계정책과 차이가 있을 수 있다.

실제 도입 시에는 기업의 계정과목 체계, 내부통제 기준,
ERP 업로드 규격 및 담당자의 승인 절차를 반영해야 한다.
